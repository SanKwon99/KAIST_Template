Duotone image: use for every content photograph so it takes the KAIST Blue accent like a screen print.

```jsx
<Duotone src="assets/photo.jpg" alt="Lab" caption="Duotone — washed in KAIST Blue." />
```

- `framed={false}` drops the hairline frame and marks.
- For PowerPoint/Slides export use the pre-baked `assets/photo-*.png` crops instead (blend modes do not export).
